# Logos de "Continuar con…" (v4.9.0)

Los botones de "Continuar con Google / Microsoft / Discord / Facebook" buscan aquí el logo
oficial de cada marca. Si falta, el botón sale solo con el texto (funciona igual).

Cada empresa pide usar SU logo tal cual, descargado de su página de marca (no lo dibujes ni lo
cambies de color):

| Archivo        | De dónde sale |
| ---            | --- |
| `google.svg`   | Google Identity → "Sign in with Google branding guidelines" → descarga el logo "G" (la versión estándar, a color). |
| `azure.svg`    | Microsoft identity platform → "Sign-in branding guidelines" → el logo de Microsoft de 4 cuadros. |
| `discord.svg`  | discord.com/branding → "Clyde" (el ícono) en blanco (el botón de Discord es azul). |
| `facebook.svg` | Meta Brand Resources → Facebook → el logo "f" en blanco (el botón de Facebook es azul). |

Tamaño: cuadrado (se muestra a 20 × 20). Formato: SVG (o cambia la extensión en js/ui/oauth-ui.js).
